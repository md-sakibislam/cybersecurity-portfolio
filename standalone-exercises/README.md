\# Standalone Exercises



Short, self-contained exercises completed as part of the Google Cybersecurity

Professional Certificate. Unlike the numbered projects, these are single

deliverables rather than multi-step case studies.



\## Data Leak Worksheet

A security review of a data leak incident where a sales team's internal

folder — containing unannounced product info and customer analytics — was

accidentally shared externally and posted publicly. The exercise applies the

\*\*Least Privilege\*\* principle (NIST SP 800-53, AC-6) to identify root causes,

recommend access-control fixes (role-based access, automatic expiration,

approval workflows, access logging), and map the incident to the NIST

Cybersecurity Framework (Protect function → Data Security category).



\*\*File:\*\* `data-leak-worksheet.pdf`



\## Update a File Through a Python Algorithm

A Python script that automates maintenance of an IP allow-list controlling

access to a restricted healthcare subnetwork. The script reads the existing

allow-list file, cross-references it against a remove-list, strips out

revoked IP addresses, and writes the updated list back to disk — demonstrating

file I/O, list manipulation, and basic automation of an access-control task.



\*\*File:\*\* `update-a-file-through-python-algorithm.pdf`
