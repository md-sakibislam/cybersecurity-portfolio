\# Drafting a Professional Statement



\## Project Description

A short professional statement exercise from the Google Cybersecurity Professional

Certificate — writing a concise, first-person summary of background, motivation,

and career focus, intended for use in resumes, LinkedIn profiles, or job applications.



\## What This Demonstrates

Practice in condensing a professional identity and career interest into a brief,

targeted statement — a common exercise for entry-level job-search materials.



\## Files

\- `docs/Professional\_statement.pdf` — the drafted statement



\## Note

This is a course exercise, and the statement as written references CISSP's eight

domains alongside the Google Cybersecurity Certificate. Worth revisiting before

using this statement externally (e.g., on LinkedIn or in applications) — CISSP is a

separate, experience-gated certification from a different body, and the phrasing

could read as overstating credentials to someone familiar with the field.
